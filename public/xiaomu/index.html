小幕 Xiaomu

开源免费的桌面影视播放器，macOS / Windows / Linux 都能装。导入自己的片源配置就能看。

小幕是一款原生桌面播放器：导入自己的 TVBox 配置、IPTV 直播列表，或直接打开视频链接。支持跨站搜索、播放中换源、弹幕、继续观看和追剧更新提醒，播放进度都存在本地。软件本身不提供任何内容，片源由你自己提供。

Windows 电脑

下载 Windows 版

安装包：xiaomu-setup-版本号-amd64.exe，双击安装

Mac 电脑 · 苹果芯片（M 系列）

下载 Mac 版（苹果芯片）

安装包：xiaomu-版本号-arm64.dmg

Mac 电脑 · Intel 芯片

下载 Mac 版（Intel）

安装包：xiaomu-版本号-amd64.dmg

不知道自己的 Mac 是哪种芯片：点左上角苹果图标 → 关于本机，看「芯片」那一行，写 Apple M 开头就是苹果芯片，写 Intel 就是 Intel。

Mac 首次打开如果提示无法验证：右键点应用 → 打开；或到「系统设置 → 隐私与安全性」点「仍要打开」。

装好之后：在首页粘贴自己的配置地址，导入就能看。

第一次用？看新手指南：配置是什么、去哪找、怎么导入
